# mossgatellc.com

Website for Mossgate LLC (Mossgate Games), served by GitHub Pages from the `docs/` folder on `main`.

- `docs/index.html`: home, games, contact
- `docs/privacy.html`: privacy policy (Google Play links to this; update it before any release that adds cloud saves, ads, analytics or accounts)
- `docs/404.html`: not-found page
- `docs/assets/`: pixel logos (from Gloammere `art/brand/pixel`), stylesheet, icons
- `docs/CNAME`: the custom domain

No build step, no cookies, no third-party requests.
