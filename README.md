# mossgatellc.com

Website for Mossgate LLC (Mossgate Games), served by GitHub Pages from the `main` branch root.

- `index.html`: home, games, contact
- `privacy.html`: privacy policy (Google Play links to this; update it before any release that adds cloud saves, ads, analytics or accounts)
- `404.html`: not-found page
- `assets/`: pixel logos (from Gloammere `art/brand/pixel`), stylesheet, icons
- `CNAME`: the custom domain

No build step, no cookies, no third-party requests.
